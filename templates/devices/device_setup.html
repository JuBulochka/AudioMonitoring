Одна команда — полная установка

Подключитесь к Raspberry Pi по SSH и выполните единственную команду: 

curl -fsSL {{ install_url }} | bash
Скрипт автоматически: установит зависимости, скачает ключи, создаст конфиг и запустит edge-клиент.
Что делает эта команда?
  1. Устанавливает autossh, python3-requests, curl
  2. Создаёт директорию ~/pumpjack-edge/ и файл .env с настройками
  3. Скачивает приватный SSH-ключ туннеля → ~/.ssh/pumpjack_tunnel_key
  4. Добавляет публичный ключ платформы в ~/.ssh/authorized_keys (для обратного SSH)
  5. Регистрирует и запускает systemd-сервис pumpjack-edge
Управление сервисом

Edge-клиент установлен как systemd-сервис — стартует при загрузке Pi, перезапускается при сбое. 

# Статус
sudo systemctl status pumpjack-edge

# Логи в реальном времени
sudo journalctl -u pumpjack-edge -f

# Перезапуск / остановка
sudo systemctl restart pumpjack-edge
sudo systemctl stop pumpjack-edge
